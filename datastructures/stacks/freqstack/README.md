# Frequency Stack

Implementation of a Frequency Stack where the data structure allows pushing elements to it and pop elements with
maximum/minimum frequency.

This supports the following operations:

- Init(): This is a constructor used to declare a frequency stack.
- Push(value): This is used to push a value onto the top of the stack.
- Pop(): This is used to remove and return the most/least frequent element in the stack.

> Note: If there is a tie for the most/least frequent element, then the most/least recently pushed element is removed
> and returned.

## Max Frequency Stack

Implementation of Max Frequency Stack where the above operations are supported.

## Min Frequency Stack

Implementation of Min Frequency Stack where the above operations are supported.
